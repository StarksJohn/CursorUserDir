## 当前工作假设
当前主导假设为：
- 优先验证一个面向患者的“手指/手外伤居家康复执行助手”，而不是泛疾病居家康复 AI 医生
- 聚焦受伤后、复位后或术后回家阶段的执行支持，帮助用户知道今天该做什么、避免什么、如何记录变化、何时准备复诊
- 产品价值优先放在执行、记录、提醒、风险提示与复诊/随访准备，而不是自动给出诊断或治疗结论
- 默认将“窄场景、强执行、可验证、可扩展”视为第一阶段产品策略
- 当前并列主候选方向为：围绕成熟游戏生态的合法 MOD / 创作者工具 / 服务器资源产品，可与康复执行助手并行比较，不再只是弱备选
- 对游戏方向的默认边界是：优先讨论 FiveM / RedM、成熟单机 MOD 生态、服主工具、作者工具、社区 SaaS 等合法且有分发路径的方向，不将外挂、作弊或破坏性对抗工具视为正式候选项目
- 对新游戏生态的默认判断是：若尚未形成清晰的官方 mod 支持、工具链和商业化路径，例如类似 Crimson Desert 的早期阶段，应降低优先级
- 对“app / 网站 / 小程序没前途”的默认回应是：载体本身不是关键，关键是是否绑定明确生态、用户场景、分发渠道与可持续价值
- 对“是否直接做单人 Steam 游戏”的默认判断是：可以作为候选方向，但通常不是最稳的第一创业切口，因为它高度依赖创意、愿望单、商店转化和持续营销
- 对“是否直接做单人手机游戏”的默认判断是：通常优先级更低，因为买量、商业化和流量竞争对独立开发者更不友好
- 对游戏行业内部方向的默认排序是：成熟生态工具/服务器产品/创作者工作流 > 合法 MOD/资源产品 > 单人 Steam 游戏 > 单人手机游戏
- 当前游戏方向的更细化假设是：第一枪优先做 `配置 / 安装 / 兼容性 / 交付` 类工具型产品，而不是通用后台、常规 job script 或完整独立游戏
- 当前市场调研的默认焦点是：在 `FiveM` 与 `RedM` 之间选择更适合首发的生态，并在 `资源配置器`、`安装检查工具`、`兼容诊断工具`、`作者交付工具` 之间选出第一款产品
- 当用户对 `FiveM` / `RedM` 本身并不熟悉时，默认先用通俗语言解释为“GTA V 私人服务器生态”和“RDR2 私人服务器生态”，避免直接用社区黑话做选择题
- 当用户尚未接触过两个生态时，默认起步建议优先看 `FiveM`，因为其社区、资料、案例和工具化机会更大，更适合快速理解市场并拿到第一轮反馈
- 当用户质疑“为什么不做 GTA Online 官方生态而要做私人服务器生态”时，默认从“第三方可进入性、可交易产品位、是否存在服主/作者这类付费角色”来回答，而不是只比较总玩家数
- 对该问题的默认结论是：官方 GTA Online 总盘子可能更大，但对第三方开发者并不开放；FiveM / RedM 私人服务器生态虽然更小，却更适合合法销售工具、资源和工作流产品
- 默认把 `服主` 解释为：私人服务器的拥有者、运营者或核心管理员，是最接近购买工具与资源决策的人
- 当用户问“为什么不兼顾其它热门游戏”时，默认强调：不是不能扩，而是独立开发者第一阶段应优先选择一个单一成熟生态，把“客户-产品-付费”闭环先跑通
- 对“GTA Online 官方周边能不能赚钱”的默认结论是：可以，但更适合做不介入官方在线玩法的外围 companion / tracker / planner / data 产品，而不是当前第一主线
- 对游戏方向的阶段性排序补充为：第一阶段优先单一开放生态里的工具链产品；第二阶段再考虑扩到其它热门游戏或 GTA Online 官方外围产品
- 对 `FiveM 服主` 市场的默认表述必须保持谨慎：可以说其生态已达到数万服务器量级、存在真实付费资源与托管市场，但不能伪称已经精确掌握服主人数或已证明全体付费意愿很高
- 对“配置 / 安装 / 兼容性”这类工具型切口的默认表述必须是：当前高概率、值得优先验证的假设，而不是已经被证实的主要付费需求
- 对现有竞品与替代方案的默认表述必须包含：txAdmin、官方/社区文档、config generator、installer、starter packs 等现有方案已经存在；机会若成立，更可能来自碎片化和体验缺口，而不是“市场没有工具”
- 如果用户明确要求“目标用户至少几百万”，则默认不再把 `FiveM 服主工具` 视为主方向，只能保留为小而美备选
- 在上述条件下，游戏方向的主线应默认转向：`GTA Online` 官方外围玩家产品、面向大盘 mod 玩家的工具，或其它具备百万级目标用户的游戏外围产品
- 对此类用户约束的默认结论是：早期更容易成交的小众 B 端方向不等于适合当前目标，用户盘规模约束应优先于“小而美变现效率”
- 在上述条件下，默认不再优先讨论 `FiveM` 服主、脚本作者、资源卖家这类小盘决策者，而应优先讨论玩家向、数据向、companion 向的大盘产品
- 当用户同时要求“目标用户至少几百万”与“也要最容易先赚钱”时，默认不要把问题简化成“大盘 vs 小盘”，而是转向分析“大盘生态中的高意图子群体”
- 对该约束的默认结论是：最容易先成交的小盘决策者与最大的大盘泛用户通常不是同一类人；更现实的主线是寻找大生态内高频、高意图、工具需求明确的玩家细分人群
- 在当前约束下，对三个主候选方向的默认综合排序是：`GTA Online business / grind / cooldown 工具` > `GTA Online 收藏 / 地图 / 进度管理工具` > `面向大盘 mod 玩家的安装 / 配置 / 兼容工具`
- 对该排序的默认解释是：`business / grind` 工具在用户盘、频次、留存、付费张力与复杂度之间最平衡；`收藏 / 地图` 更偏流量友好；`mod 玩家工具` 更偏长期价值但第一枪复杂度偏高
重要说明：
- 将其视为当前优先探索方向，而非固定承诺。
- 若用户提出更有力的方向，应客观评估，而非强行绑定康复设想。
