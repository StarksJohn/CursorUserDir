## 当前免费 AI 能力判断
- `乙游`：通常指面向女性用户的恋爱互动叙事产品
- 当前更适合的产品表达：`轻乙游化的聊天陪伴 app`
- 当前结论：`免费 AI API 可以做原型，不适合做正式产品的长期聊天底座`
- 原因摘要：
  - `OpenAI API`：当前没有稳定官方免费层
  - `Claude API`：当前没有官方免费 API 层
  - `Gemini API`：有免费层，但更适合开发者和小项目试用
  - `OpenRouter free`：可用于原型，但免费模型存在限流、可用性和延迟波动
- 默认产品策略：
  - 第一版不要做 `无限自由聊天`
  - 优先做 `强约束聊天 + 章节推进`
  - 优先采用 `预写剧情分支 + 少量 AI 润色/回复`
