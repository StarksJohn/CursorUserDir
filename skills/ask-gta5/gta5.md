## 1. 制造厂：还要不要买第二张图里的？

**结论：一般不需要。**

- 第一张图（您拥有的制造厂）：你已拥有摩托帮「The Open Road」下的 **五类各一间**——假钞、证件伪造、大麻、冰毒、可卡因，且库存/原材料都有积累。
- 第二张图（购买制造厂）：是 **同一类生意在不同地点的房源**，不是「第六种厂」。线上规则是 **每种类型同时只能持有一处**；再买同类型会先处理掉原有地点（换址），不会叠两间同类型厂一起产货。
- **只有在**你想换地点（例如缩短出货路程、个人偏好地图位置）时，才需要考虑从列表里另买一处并替换；**不为多赚钱而重复购买同类型**。

## 2. 服务载具 + 夜总会 + 地堡：要不要多买几间夜总会/地堡？

**夜总会、地堡：通常各一间即可，不必为多赚钱再各买第二间。**

- **夜总会**：一间即可同时跑人气收入、仓库挂机、与多种生意挂钩；第二间夜总会对多数玩家 **性价比很低**。
- **地堡**：制造与研究（或纯制造） **一间升满** 即可；第二间地堡很少有必要。
- **服务载具**（你提供的交互菜单截图）：列表含游艇、机动作战中心、复仇者、恐霸、虎鲸、致幻剂实验室等。截图说明里 **银河超级游艇当前显示为未持有**（需去 DockTease 另购才算拥有）。其余若已购买：**不必为效率重复买第二套同类**（例如第二辆恐霸、第二艘虎鲸），除非你有明确玩法或收藏需求。

## 3. 接下来怎么赚钱相对最快？（按常见效率与可 solo 程度）

以下为通用优先级思路，实际以当周活动加成、你是否有人组队为准。

1. **佩里科岛（虎鲸 + 上岛抢劫）**  
   仍是最稳的 **单人高时薪** 路线之一；已有虎鲸则优先熟练路线、主目标 + 次要目标。

2. **地堡 + 摩托帮五厂 + 夜总会仓库（挂机链）**  
   你已具备 MC 五厂与地堡、夜总会：  
   - 保持 **原材料**（偷或买）与 **出货** 节奏；  
   - 夜总会人气与仓库在 **挂机玩法** 里很省心，适合与上岛、小任务穿插。

3. **致幻剂实验室（酸厂）**  
   若已在 Freakshop 解锁并升级，可作为 **补充产线**，与出货轮次一起规划。

4. **事务所（若尚未买）**  
   安保合约、电话暗杀、德瑞合约等 **现金与经验** 都不错，且流程相对固定。

5. **限时活动**  
   每周查看 Rockstar 公告：**双倍/三倍** 的差事、抢劫或出货类型优先打，同样时间收益更高。

## 7. 单人：硬闯和潜行哪个更简单？要不要做「潜水艇：虎鲸」前置？

### 硬闯 vs 潜行（单人）

- **硬闯**：不必记复杂巡逻与摄像头节奏，玩法上「见敌就打」；一旦触发警报，岛上与豪宅内 **增援、重甲、火力密度** 会明显上升，**单人没有队友拉枪线**，血甲与弹药消耗大，**未必比潜行更容易稳过**，尤其首通。
- **潜行**：需要 **学习路线**（击倒顺序、避开视野、可选下水道入侵等），前几把有成本；熟练后往往 **交火少、节奏可控、复活少**，反复刷岛时多数玩家认为 **更稳、更省心**。
- **简要结论**：**论「长期最简单」**：通常更推荐 **潜行（配合排水隧道等）**。**论「当下不想背板」**：硬闯更直觉，但 **不要默认硬闯一定更简单**；若枪法与补给一般，可先试潜行攻略视频跟跑一两遍再决定。

### 接近载具里的「潜水艇：虎鲸」要不要做？

- 前置页 **接近载具 0/5** 表示五种里你 **尚未完成任何一种**；终章需要 **先选定并完成至少一种** 接近方式。
- 你当前选中 **「潜水艇：虎鲸」** 且界面标注 **「前置工作：必要任务」**：若确定用 **虎鲸** 上佩里科岛，就 **必须完成这一项** 对应任务，不能跳过。
- **不需要**把阿尔科诺斯特、梅杜莎、巡逻艇、长鳍 **全部** 各做一遍；**只做你选定的那一种** 即可。若改选其他载具接近，则去做 **那一项**，虎鲸这项可不选/不必做。

### 8.4 「大地图」是不是情报页这张？排水隧道要不要去围墙边的三角标？

**排水隧道是否要去「红色箭头」那种围墙旁的三角标记**：**不需要。** 围墙上/围墙外的 **小三角** 一般是 **正门、北墙、北大门、南墙、南大门** 等 **陆地类豪宅入口**，与 **排水隧道** 无关。**排水隧道** 在豪宅 **朝开阔海面一侧** 的 **水下**，需 **潜水** 找到 **排水格栅 / 洞口** 并完成侦察，才会在情报里解锁 **「排水隧道」**（例如从豪宅入口 5/6 补到 6/6）。

### 8.6 搜集情报：主目标侦察完成了吗？能回去了吗？（对话列表能说明什么）

**主目标侦察完成了吗（结合你提供的「信息 → 对话」截图）**：**仅凭该列表不能认定已完成。** 常见流程里，**主目标**（首通为 **玛德拉索文件**）需在 **通讯塔** 骇入监控后，用 **摄像头** 对准豪宅 **地下室/金库** 内主战利品才会触发对应确认与帕维尔台词。你截图中的对话集中在 **主码头、次要目标、排水管道、切割炬** 等，**未见** 典型的 **主目标/金库内容已识别** 一类表述，因此 **更可能仍缺主目标侦察**——最终以 **虎鲸计划板「情报」页右侧主目标是否已显示且数值正确**、以及 **通知** 里是否出现过主目标侦察完成 为准。

**排水管道 / 排水隧道侦察**：若游戏中出现 **「您完成了对一个豪宅入口点的侦察：排水管道」**（或通知中的等价文案），且水下已对 **金属格栅** 完成拍照，则 **该豪宅入口项已完成**。

**完成了排水能不能马上收工离岛**：**不一定。** 「搜集情报」整轮通常还要求 **主目标** 等必做侦察。若 **主目标尚未通过通讯塔流程完成**，建议 **补拍后再** 按任务指引 **离岛**（如前往机场等），避免回洛圣都后发现计划板仍缺项、需要再上岛。

**为什么「人在红点附近」仍找不到格栅**：暂停地图上的点若在 **豪宅东侧** 水陆交界，与 **南/西南外海崖脚** 的格栅 **不是同一位置**；需 **绕到宅子南端外海**，**深潜** 沿 **崖壁根部** 搜索，直至出现侦察提示。

### 8.7 第二轮及以后：刚交 setup 费后，「搜集情报」还要注意什么？

适用于 **已完成过至少一次** 佩里科岛终章、再次从虎鲸计划板开始新轮、系统已收取 **$100,000**（价格以游戏内为准）后的 **搜集情报**（与你提供的 `img_cayo_intel_second_run.png` 界面一致：左侧 **入侵/逃离/豪宅入口** 多为历史进度，**次要目标** 可能本轮尚未列出）。

**与首通最大的不同**

- **主目标不再固定玛德拉索文件**，会进入 **随机主目标**（粉红钻、项链、龙舌兰酒、不记名债券等——以本轮骇入后计划板显示为准）。**每一新轮都要** 上岛 **通讯塔骇入 → 监控摄像头对准金库/主战利品**，直到 **情报页出现明确主目标与金额**；**不能** 以为首通关过一次就自动带主目标。
- **次要目标**（各库房现金/可可/大麻/黄金/画作等）通常 **每轮刷新**，左侧 **「次要目标」** 在本轮侦察前可能为空或需重拍。**打算吃次要** 就按黄点/任务指引 **重新拍照**；若走速通且只要有主目标也可在 **确认主目标+选定入侵够用** 后收手（与 §8.1 速通思路一致）。

**往往不用再整岛重跑的**

- **入侵点 / 逃离点 / 豪宅入口**（你截图里 **6/8、4/4、6/6** 类进度）多为 **已解锁继承**；若仍含 **排水管道** 等你惯用路线，**不必** 仅为凑满 **8/8 入侵** 再全图扫一遍，除非你想换新上岛方式。
- **兴趣点**（如 **1/6**）：仍只在你 **本轮打法需要** 时补（螺栓切割器、抓钩、卡车等）；**只走排水隧道** 时 **不必** 强行刷满 6/6，见 §8.1。

**流程清单（简）**

1. **必做**：通讯塔流程 → **确认本轮主目标**；计划板右侧主目标区域有 **正确品项与估值** 再视为情报主项完成。  
2. **按需**：次要库房 **拍照**；缺 **排水隧道** 则下水补格栅侦察（§8.4～8.5）。  
3. **离场**：以 **任务提示 / 帕维尔** 为准；**主目标未出** 不要当「这轮情报已经好了」就撤。  
4. **若主目标太惨**：部分玩家会选择 **取消这次抢劫/重开情报** 以换一批（涉及时间与再次付费，**非必须**，自行权衡）。

### 8.8 第二次及以后：「搜集情报」**只须**搞定哪些 **主要 / 次要**？（`img_000510.png`）

适用于 **已完成过至少一次终章**（含 **纯潜行**）、再次从虎鲸 **情报 → 搜集情报** 上岛的情形。**与 §8.7 一致**，本节用你提供的 **`img_000510.png`** 作界面锚点：左侧为 **入侵 6/8、逃离 4/4、豪宅入口 6/6、兴趣点 1/6**，左下角任务为 **「在佩里科岛找到主要目标」** —— 表示 **本轮主目标尚未通过通讯塔流程确认**。

![虎鲸计划板 · 情报页：搜集情报；入侵 6/8、逃离 4/4、豪宅入口 6/6、兴趣点 1/6；当前目标「在佩里科岛找到主要目标」](img_000510.png)

**主要目标（每轮必做）**

- **每一轮新抢劫**都要重新确认 **本轮主目标**（粉红钻、项链、龙舌兰酒、不记名债券等——以骇入后为准），**不会**沿用上一轮结果。
- **流程**：上岛后去 **通讯塔** 骇入监控 → 用 **摄像头** 对准 **豪宅金库/主战利品** 直至计划板 **右侧主目标区出现品项与金额**（或等价完成提示）。**未完成这一条**（如截图左下角仍提示找主目标）**不要**当情报已结束就离岛。

**次要目标（想做才拍）**

- 各 **库房** 的现金 / 可可 / 大麻 / 黄金 / 画作等 **通常每轮刷新**，要在本计划里吃到次要，就按地图 **黄点** 进点 **重新拍照** 侦察。
- **若你只想尽快结束情报、终章只打主目标**：在 **主目标已确认** 且 **前置计划里已能选惯用入侵/撤离**（例如仍保留 **排水管道**、逃离点已齐）的前提下，**次要可以少拍或不拍**（分红会少一块次要钱，与 §8.1 速通思路一致）。

**现在以及以后重复做情报时，通常不必每轮补满这些**

- **入侵点 8/8**、**兴趣点 6/6**：**不**是主/次目标的硬性要求；**纯潜行走排水管道** 时 **不必** 为速通刷满（§8.1）。你截图里 **6/8、1/6** 仍可开局，只要 **主目标已确认**、终章能选 **排水管道** 等即可。
- **逃离 4/4、豪宅入口 6/6** 等 **多为历史继承**：若列表里已有常用项，**不必**整岛重扫一遍。
- **兴趣点**（螺栓切割器、抓钩、卡车等）：**仅当**你本轮路线 **仍依赖** 某一项且地图未标时再补 1～2 次侦察；**只走隧道** 往往 **不必** 凑满 **6/6**。

**最短清单（背板用）**

1. **必做**：通讯塔 → **主目标** 出。  
2. **按需**：要次要钱 → 拍 **次要库房**；不要 → 可跳过。  
3. **按需**：缺 **排水隧道** 或 **某撤离** → 按 §8.4～8.5 补；否则沿用继承进度即可。

**次要是否「每轮都要两人」**（与 `img_000510` 等情报轮次无关的独立规则）

- **不是**所有次要都要双人：**豪宅内双门黄金** 需 **两名玩家同时** 在两侧互动才能开门搬满（与 §6 一致）。  
- **机场/码头等库房** 的现金、可卡因、大麻、**画作** 等，**单人** 通常可按点位拿取；是否拿满受 **背包容量** 与 **时间** 限制。  
- 每轮情报里 **拍照次要** 只为 **估值与地图标注**；**不**等于「拿了就必须双人」。

- **装备 2/4**：计划板 **未打满**，说明仍有 **必要装备**（常见为 **指纹复制器** 等）**未完成**。进豪宅内 **骇入门禁 / 金库流程** 往往 **必须** 拿到 **指纹复制器**；**割炬**（排水管道）、**等离子切割枪**（红宝石项链展柜）你已勾上，**仍缺** 的项须 **各做一次前置任务** 直至 **4/4**（或你当代计划板显示 **全部完成**；具体四项名称以 **游戏内** 为准）。
- **接近载具 1/5**：表示 **五种接近里已完成你所选路线对应的一条**（如 **虎鲸**）；**不必** 为凑 **5/5** 把五种载具全做。
- **武器装备 1/1**：**阴谋者** 等已 **完成** 对应任务即可。

**你该做什么**：进入 **装备** 子栏，对 **未打勾** 且标注 **必要任务** 的条目 **回车开始任务** 并做完；**不要** 指望靠 **干扰** 解锁终章。若某项在 **你的** 界面上写 **可选**，且其余必要项已满，才可跳过（以 **Tab 情报说明** 为准）。

## 10. 非公开好友战局：如何给同战局好友发短信

**场景**：你已加入 **非公开好友** 战局，战局里只有你与另一名好友（玩家列表见 `img_003719.png`）；打开手机 **短信** App 只见 **「无消息」**（`img_003831.png`），想知道怎么给对方发短信。

### 10.1 为什么短信里是空的？

- **「短信」界面**主要显示 **已有往来 / 系统与 NPC 类消息**；没有对话时会显示 **无消息**，**不代表**你不能主动联系玩家。
- **主动发给玩家**通常要先 **选定收件人**（玩家列表或联系人），而不是在空白短信页里「新建一封」。

### 10.2 推荐操作（优先）

**方法一：暂停菜单里的玩家列表（最稳、不依赖手机联系人是否显示）**

1. 按 **ESC**（键盘）打开 **暂停菜单**。  
2. 进入 **「在线」**（或顶部与 **GTA 在线模式** 相关的分页，具体以当前版本界面为准）。  
3. 打开 **「玩家」** / **当前战局玩家** 列表（名称可能随更新略有不同）。  
4. 在列表中 **选中你的好友**（与 `img_003719.png` 里另一位玩家同一用法）。  
5. 在 **右侧说明栏** 或 **互动键提示** 中找到 **「发送短信」** / **「发信息」** 等选项并确认。

发信后，对方会收到；之后你打开 **手机 → 短信**，也可能出现与对方的会话记录。

**方法二：手机联系人**

1. 打开手机，进入 **「联系人」**（不要停在只有收件箱的 **「短信」** 一页）。  
2. 在列表里查找 **该好友或在线玩家**（若列出）。  
3. 选中后选择 **发短信** / **发送信息** 类选项。

若 **联系人里没有** 该玩家，请仍用 **方法一**。

### 10.3 若看不到「发送短信」

- 到 **设置 → 在线 / 显示 / 沟通**（路径以游戏内为准）检查是否 **限制与玩家发消息** 或相关隐私选项。  
- PC 上若界面异常，可尝试通过 **Rockstar Games / Social Club 好友列表** 确认好友关系；极少数情况下存在客户端或会话显示问题，可换战局或重启游戏再试。

## 11. 「防爆」代步：夜鲨 还是 美德满改？

**结论先说**：两车都叫常用 **防弹/高抗爆** 选择，但侧重点不同——**夜鲨**更像 **装甲 SUV、硬扛爆炸与任务车**；**奥北 美德（Ocelot Virtue）满改** 在常见的「满改」语境里通常指 **事务所车库 + Imani Tech**（**导弹锁定干扰器** + **装甲** 等），更像 **防 Mk2 点名 + 超跑机动**。**能免费拿到美德且舍得事务所改装投入时，日常综合往往更偏美德**；**只图一辆耐揍、好买、好跑货的装甲车** 时 **夜鲨** 依然极强。

### 11.1 夜鲨（HVY Nightshark）

- **定位**：装甲越野车，窗缝小、生存向，长期被用作 **出货、跑路、战局摩擦** 的保守选择（你提供的 Warstock 页见 `img_warstock_nightshark.png`；价目随周活动变化，以游戏内为准）。
- **长处**：**朴素耐打**、越野通过性好、可载多人；对 **不会 / 不能** 依赖导弹锁定的火力仍很能扛。
- **短处**：**没有** Imani 那种 **防锁定**；面对 **会玩的固定武器 / 扫射补刀** 仍会翻；与超跑比 **速度和灵活性** 不占优。

### 11.2 美德 + 「满改」（一般 = Imani Tech）

- **获取**：完成 **最后一剂** 相关任务线后可 **免费获得** 载具本体（与评论区说法一致，以你存档进度为准）。
- **「满改」核心**：在 **事务所（事务所车库载具改装）** 为美德安装 **阿尼玛科技 / Imani Tech**（简体中文版菜单名 **伊玛尼技术**，见 §11.6 截图）——常见组合为 **导弹锁定干扰器**（在 **伊玛尼技术 → 遥控** 子菜单内；显著减弱 **Mk2 等锁人导弹** 威胁）与 **装甲板 / 防御类**（主改装列表中与伊玛尼条目并列，提升对抗爆炸与枪械的生存）。另有 **遥控单元** 同属伊玛尼线，偏 **远程遥控载具** 玩法，与「防锁」不同项。评论里把 **防锁 + 防爆装甲** 一并归在 Imani 下，**大体方向对**，但 **没有真正「绝对炸不坏」** 的车，仍要避免被原地集火或黏弹糊脸。
- **长处**：**机动强**、有 **防锁** 时在公开战局 **体验往往比夜鲨省心**；任务外 **赶路** 也更轻快。
- **短处**：需要 **事务所 + 改装花费**；车身低矮，部分人 **更习惯夜鲨的 SUV 视野与通过性**。

### 11.3 怎么选（简表）

- **图 1**（`img_virtue_imani_tech_menu.png`）：**F 克林顿与合伙人** 载具改装间，左侧大类选中 **「伊玛尼技术」**，说明为「伊玛尼的自定义改装。」——即 §11.2 所述入口。同屏主列表里 **「装甲板」** 等通常在 **伊玛尼技术** 上下方单列，**抗爆 / 抗揍** 往往要 **装甲** 与 **伊玛尼** 分开点满（价目以游戏内为准）。  
- **图 2**（`img_virtue_imani_remote_jammer.png`）：进入 **伊玛尼技术** 后，子界面标题为 **「遥控」**。其中：  
  - **导弹锁定干扰器**：说明为防制导导弹锁定个人载具 —— 即正文 **「防 Mk2 一类锁定」** 的核心件；  
  - **遥控单元**：遥控驾驶用，**不是** 防锁本身，属同子类下的 **另一项** Imani 升级。

## 12. 除夜鲨 / 美德外：公开战局里还有哪些「更抗揍」的 PVP 向选择？

**先说清「抗揍」**：公开战局里死亡往往来自 **锁定导弹、机炮、黏弹集火、狙线拉窗** 等。**皮实耐炸** 与 **不让对手锁你** 是两条线——后者正是 §11 **美德** 一类 **Imani 防锁** 的强项；前者则是 **装甲皮卡、坦克、重卡车头** 等更占优势。下面列的是 **常与夜鲨 / 美德并列讨论**、在 **生存或反制** 上有一席之地的载具类别（**不以「绝对排名第一」排序**，实际看对手拿什么、你有没有队友）。

### 12.1 重装甲陆地载具（偏「硬吃伤害」）

- **HVY 叛乱分子皮卡·改装（Insurgent Pick-Up Custom）**  
  多人战局经典 **装甲皮卡 + 顶机枪**；**有炮手** 时压制力强，车体也 **极能扛**（具体耐受随版本，以实测为准）。缺点：**造价与解锁** 比夜鲨折腾，无炮手时更多靠车体硬顶。

- **HVY 威胁者（Menacer）**  
  与夜鲨同一大类的 **装甲 SUV + 炮塔**，玩法接近 **「更重火力的夜鲨替代品」**；是否值得买看个人预算与是否缺机枪位。

- **TM-02 可汗贾利（Khanjali 坦克）**  
  **陆上顶点级的「肉」之一**，主炮克载具；缺点是 **慢、贵、目标极大**，公开图里 **极易被飞机 / 固定翼 / 会玩的武直** 针对，且自身有 **任务/设施门槛**（夜总会设施等，以游戏当前要求为准）。

- **HVY 巴拉杰（APC）**  
  **两栖 + 装甲 + 山姆防空**；**生存与反飞机** 都有说法，但同样 **笨重、贵**，更适合 **明确要用 SAM 或水路** 的玩法，而非单纯「代步」。

- **半履战车（Half-track）**  
  **前装甲厚重 + 后座双机枪**；有队友时威慑大，**扛揍能力** 常被提及；缺点是 **转向与日常通勤** 不如 SUV 灵活。

- **机动作战中心 · 牵引车头（Phantom Custom / Hauler Custom 等）**  
  **车头本体** 在熟练玩家手里 **极难被快速蒸发**（常被当作移动掩体 / 冲撞武器）；缺点是 **为拖 MOC 而生**，不是通用跑车，公开图 **攻击性拉满** 也容易引来全图针对。

### 12.2 与美德同源的 Imani 科技线（偏「防锁 + 装甲」）

除 **美德** 外，凡在 **事务所** 相关改装中对该车开放 **阿尼玛科技（Imani Tech）** 的 **轿车 / SUV**（常见如 **冒险家 牛轧糖 STX**、**白金汉 迪提**、**埃努斯 禧碧**、**巨象 爱国者 Mil-Spec**、**贝飞特 迪布达 6×6**、**威皮 卡拉卡拉追逐版** 等，**以当前版本游戏内改装厂清单为准**）均可视情况装 **导弹锁定干扰器 + 装甲**。  
**共同点**：相对 **坦克/皮卡** 更 **低调、好钻巷**；**有效生存** 往往不亚于「更肉但更显眼」的车。**与 §11 对比的两车关系**：它们是 **美德同款思路的换壳**，不是魔法无敌，**集火与无锁定爆炸** 仍会要命。

### 12.3 「邪教」级硬度（投入大、玩法窄）

- **竞技场之战** 里把 **斜面魔宝、大脚怪 SL、死亡尾翼** 等 **防御拉满** 的改法，在地面互捶时 **往往异常能顶**，但 **日常通勤、任务兼容、维修与获取成本** 通常不如夜鲨 / Imani 车省心——适合 **本来就玩竞技场** 的人顺手用。

### 12.4 和夜鲨 / 美德怎么配队选车？

| 倾向 | 可考虑 |
|------|--------|
| 继续 **SUV + 机枪 / 多人车**、要 **比夜鲨更凶的炮** | **叛乱分子皮卡·改装**、**威胁者** |
| 要 **陆上最硬 + 主炮**、接受 **笨重** | **可汗贾利** |
| 要 **防锁 + 城市车**、与美德同逻辑 | **其它 Imani 可改装载具** |
| 要 **极致掩体车头**、整活或针对性打法 | **MOC 牵引车头** |

**没有标准答案** 说哪辆「全面强于」夜鲨或美德；**多数玩家** 仍是 **Imani 车日常 + 夜鲨或皮卡任务** 的搭配。

## 13. 公开战局 PVP：「防弹 + 防炸 + 防导弹锁定」—— 哪些载具算？

**本问题未单独附带新截图**；与 §11、§12 共用下列图示作 **对照锚点**（同一目录）：

- **`img_warstock_nightshark.png`**：夜鲨偏 **抗爆 / 窗缝小**，**没有** 伊玛尼 **导弹锁定干扰器**，故 **不满足** 题述里的 **防导弹锁定** 这一条（与 §11.1 一致）。
- **`img_virtue_bilibili_nightshark.png`**：美德 **满改** 语境 = **防锁 + 装甲** 的典型讨论起点。
- **`img_virtue_imani_remote_jammer.png`**：**伊玛尼技术 → 遥控 → 导弹锁定干扰器**，即 **防制导锁定** 的改装入口（与 §11.6 一致）。
- 若需回忆 **事务所在哪买**、办公室≠事务所，可参见 **`img_dynasty8_virtue_imani_prereq.png`**（§11.5）。

### 13.1 先把话说死：没有「三项绝对免疫」

线上 **没有** 官方定义的、对 **所有子弹 / 所有爆炸 / 所有锁定方式** 同时 **永久无敌** 的个人载具。**骷髅马（装甲版）** 防弹突出但 **怕炸**；**夜鲨 / 坦克 / APC** 等再硬也 **不能** 靠原厂配置 **关掉** 制导导弹的 **锁定**（需 **伊玛尼导弹锁定干扰器** 或其它机制）。题述「三防」在玩家语境里一般指：**显著防弹窗或难拉窗 + 高抗爆 + 不能被制导弹锁**。

### 13.2 最接近「三向都要」的配置：伊玛尼 **装甲板 + 导弹锁定干扰器** + **100% 装甲**

在 **F 克林顿与合伙人 · 事务所 · 载具改装间**（前提见 §11.5）中，对 **当前版本支持该两项伊玛尼改装** 的载具：

1. **导弹锁定干扰器**（`img_virtue_imani_remote_jammer`）：使 **制导发射器、Mk2、多数武直/喷气机载具的制导导弹** 等 **无法对你个人载具建立锁定**（仍以游戏内说明为准）。
2. **装甲板**（伊玛尼）：在 **100% 车身装甲** 且 **车内有人** 时，社区与维基常见表述为可 **多扛** **跟踪导弹 / RPG** 一类伤害（量级随 DLC 微调，**以你当前增强版实测为准**）。
3. **防弹**：多数为 **防弹玻璃 / 装甲外观件 + 窗线**，**不是** 全向无敌；高窗 SUV（如 **埃努斯 金钻耀星** 等）与低趴轿跑在 **被扫窗、黏弹贴脸** 时体验差很多。

**结论**：满足题述 **三项在「实用 PVP」意义上同时成立** 的，是 **这一类拉满的伊玛尼车**，而不是 **仅夜鲨 / 仅骷髅马 / 仅坦克** 中的任一辆单解。

## 14. 已有事务所 + 虎鲸：还要买哪些资产赚钱？

**本问题未附带新截图。** 若需把「事务所」与 **伊玛尼改装间**、办公室分页区分，可对照 **`img_dynasty8_virtue_imani_prereq.png`**（§11.5）、**`img_virtue_imani_tech_menu.png`**（§11.6）。赚钱总览仍与 **§3** 一致；此处只回答 **在已持「F 克林顿与合伙人」+「虎鲸」前提下**，还值得考虑 **补哪些产业**。

### 14.1 先定心：这两样已经覆盖什么？

- **虎鲸**：**佩里科岛抢劫** —— 长期 **单人现金效率** 的顶流之一；会跑岛则 **不必**为「再赚快钱」强买另一条同质主线。
- **事务所**：**安保合约**、**电话暗杀**、**别惹德瑞**（及流程解锁条件）、**合约档案** 等 —— **中短差事 + 大型合约** 现金与经验都稳。

**结论**：没有「必须再买 X 才能赚钱」的硬门槛；下文是 **扩宽收入来源 / 挂机 / 玩法向** 的 **可选项**。

### 14.2 优先考虑的「现金向」补充（按常见性价比，缺啥买啥）

1. **夜总会 +（可选）摩托帮制造厂 + 地堡**  
   - **夜总会**：人气收入 + **仓库挂机**（需与 **摩托帮五类厂 / 地堡** 等挂钩才「仓库有货可囤」——具体以你当前存档为准）。  
   - **地堡**：制造或研究；纯赚钱常开 **制造** 并 **补原材料 + 出货**。  
   - **摩托帮厂**（假钞、证件、大麻、冰毒、可卡因等）：每类 **同时只能一处**（§1）；不必同类型买两间。  
   - **与 §1～§2 一致**：夜总会、地堡 **各一间升满** 通常足够，**不要**为多赚钱再买第二间同产业。

2. **致幻剂实验室（酸厂 / Freakshop 线）**  
   - 解锁并升级后，作为 **补充产线** 与出货轮次穿插（§3）。

3. **改装铺（汽车店）**  
   - **合约任务** + 联合抢劫类内容；适合想 **换口味、solo/小队皆可** 的玩家。

4. **回收站（Salvage Yard / 拆车）**  
   - **策划与交付** 类玩法，现金与流程固定度因周活动而异；适合作为 **另一条主动收入**。

5. **办公室（CEO）+ 载具仓库** 或 **特种货物仓库**  
   - **进出口**、**拉货** 偏 **传统肝钱**，需学习出货与战局风险；**不是**人人都有时间跑，但 **资产本身** 可解锁 **暴君 Mk2 折扣** 等（以当前版本为准）。

6. **游戏厅 / 设施**  
   - **名钻赌场抢劫**、**末日豪劫** —— **偏组队、流程长**；有固定队友时 **单次分红** 可观，**不比** 上岛 **更适合单人碎片时间**。

7. **机库、游艇等**  
   - **机库** 空货、**游艇** 任务 —— 多数玩家 **不作为** 主现金线；除非你喜欢玩法或当周 **三倍**。

### 14.3 不建议的「重复购买」

- **第二艘虎鲸、第二间事务所、第二间夜总会、第二间地堡** —— 对多数账号 **性价比极低**（§2）。  
- **同类型摩托帮厂买两处** —— 只会 **换址**，不会叠两间同类型产出（§1）。

### 14.4 实操顺序（简）

| 你更想…… | 可优先补 |
|----------|----------|
| **挂机 + 周期性出货** | 夜总会、地堡、摩托帮厂（若尚未持有或未满级） |
| **再多一条 solo 差事线** | 酸厂、改装铺、回收站 |
| **组队大抢劫** | 游戏厅（赌场）、设施（末日） |
| **传统 CEO 肝货** | 办公室 + 特种货 / 载具仓 |

**每周**看 Rockstar **Newswire** 的 **双倍/三倍**：哪条线加成高，就 **短期内优先** 哪条线，往往比「再买一栋房」更涨收入。

## 15. 摩托帮五厂出货：能否用飞机装摩托、拖车拉大车？

**§15.1～§15.3** 无附图；**§15.4** 含 **`img_154815.png`～`img_155402.png`**（证件伪造换址）；**§15.5** 含 **`img_mc_trade_lose_stock.png`**（换购清空提示）。与佩里科岛相关的图示仍以 **`img_000510.png`～`img_005629.png`**（情报与前置）、**`img_015344.png`～`img_015436.png`**（终章卡关与干扰）为准，见 **§8.8～§8.11**。

### 15.1 更快的飞机能否把「送货摩托车」装进去？

- **没有**面向 MC 出货的、像「打开舱门把任务摩托开进运输机」这类 **稳定合法流程**。**复仇者** 机库、**邦布须克** 等载具货舱玩法 **不用于** 摩托帮出货任务链；任务开始后系统刷出的 **送货载具** 与 **个人飞行载具** 是两套逻辑。
- **运兵直升机 / 吊挂型直升机（如 Cargobob 类）**：自由模式里可对 **部分** 普通载具使用吊钩，但 **摩托帮/地堡等生意出货** 生成的车辆 **多为任务专用**，**无法**作为常规手段依赖——常见结果是 **钩不上、任务不计进度、直接失败或随版本被限制**，**不应**当作省时间的攻略前提。
- **暴君 Mk2 等**：只能当 **自己赶路或清 NPC** 的随行载具，**不能**替代「把货摩托装进飞机」。

**结论**：想靠「飞机运摩托」把 MC 出货变短 —— **基本不成立**；路远问题要从 **厂址、货量、战局** 上想（见下）。

### 15.2 拖车能否牵引「送货大卡车」更快赶路？

- **不能**指望。出货任务里的大卡 / 厢型 / 垃圾车等是 **任务实体**，路线与停靠点由任务脚本约束；**另找一辆拖车去牵引任务车** **不是** 设计内的加速方式，多数情况下 **不可行或会搞砸任务**。
- 自由模式里卡车与拖车的部分挂钩玩法 **不迁移** 到这类出货差事上。

### 15.3 实际能缩短痛苦、降低翻车率的手段

1. **换厂址（§1）**：摩托帮 **同一类型只能持有一处**，若当前厂在 **沙漠/北缘**、出货总往洛圣都跑，可考虑 **卖掉换到更靠南、靠路网的地点**（一次性成本 + 适应新偷货/出货习惯）。  
2. **非公开好友 / 单人战局出货**：不缩短公里数，但 **少被玩家截胡**，心理与时间损耗小很多。  
3. **控制库存分批卖**：库存 **未满** 时单次出货 **车辆更少**、部分随机类型更友好（牺牲单次最高收益换稳定）。  
4. **夜总会仓 + 统一出货**：若走挂机链，由夜总会 **攒够再出** 是另一条节奏，与「单厂急出」不同，可按玩法选择。

### 15.4 证件伪造换址：葡萄籽卖洛圣都远，三选一选哪？（`img_154815.png`～`img_155402.png`）

**现状（`img_154815.png`）**

### 15.5 换购制造厂时，满仓会不会没了？（`img_mc_trade_lose_stock.png`）

**实操建议**

- 想保住满仓价值：**先完成一次出货**（或至少卖掉大部分库存）再换址。  
- 若宁可不要这批货、只想立刻搬家：可 **确认换购**，接受 **从零开始**。

## 17. 游戏厅：游戏机买满了为什么保险箱还是很穷？

本问题 **未附带截图**。以下为 **Diamond Casino Heist「游戏厅」产业**（办公室保险箱）机制说明，与前文佩里科 **计划板卡住**（`img_015344.png`～`img_015436.png`，§8.11）为 **完全不同系统**，勿混为一谈。

### 17.1 设计如此：封顶就很低

- 维基与长期社区口径一致：**所有专用游戏机位上都摆了游戏机**（机位加满）时，被动收入 **最多约 `$5,000`／「游戏日内」**（常被说成约 **48 分钟** 现实时间与「在线上自由模式挂机」相关联，**以当前增强版实测为准**）。  
- 因此就算你 **花几百万把机台配齐**，保险箱 **也不会变成夜总会或地堡同级别**——游戏厅主要靠 **赌场抢劫计划板**，被动只是 **小钱**。

### 17.2 保险箱有上限 —— 满了就「不涨」

- 保险箱储量 **有封顶**；《合约》等大更新后有资料称上限约 **`$100,000`**（旧版曾常见 **`$50,000`** 说法）。  
- **满额后不再往里堆钱**，看起来像「收入很少」，其实是 **需要去办公室互动把钱拿走**，否则浪费了后续 `$5k`/日的堆叠窗口。

### 17.3 买满≠一定「机位加满」的检查项

- 封顶条件一般是：**游戏厅层楼里每一个可放置游戏的插槽都有一台主机** ——用的是 **占位数量**，不是你在外网买了多少 **最贵** 的机种。维基写明：**游戏机品种/单价不影响顶格被动**，只要把 **位子填满**。  
- 若仍明显低于封顶：进游戏厅看 **地板上是否仍有空桩位**；在 **办公室的 Pixel Emporium 笔记本** 里确认采购是否与实际摆放一致。

### 17.4 和什么比会像「很少」？

- **夜总会** 人气挂机、**地堡/MC 出货**、**佩里科** 单次分红，量级都远大于游戏厅被动；体感「买满还很穷」多数是 **期望值设错**。  
- 真想靠产业躺钱：**夜总会挂机链 / 事务所 / 上岛**，游戏厅保险箱当 **顺带领零花**。
