# Chinese–English Translation

## 默认执行策略

- **默认目标**：每次调用本 skill 都交付**可直接采用的译文** + **可核对含义的语法说明**，而不是只给一个词对等。
- 当用户说「补规则 / 优化翻译 skill」时，默认直接完善本 skill，仅在以下情况再追问：
  - 中译英与英译中在同一句里混用且目标语种不明
  - 必须保留品牌大小写、法律用语或固定官方译名，但未给出约束
  - 原文严重残缺、无法判断领域（医学/法律/游戏等专名风险）
- 若输出仍缺「语法说明」或违反「英译首字母小写」约定，视为未完成，须在**同一条回复内**补齐或更正。

## 输入格式说明

在 Cursor 中输入 **`@chinese-english-translation`**，可附带语境：

| 输入示例 | 说明 |
|----------|------|
| `@chinese-english-translation` + 粘贴原文 | 根据原文语言自动判断中→英或英→中 |
| `@chinese-english-translation 中译英` + 句子/词组 | 强制中译英 |
| `@chinese-english-translation 英译中` + 句子/词组 | 强制英译中 |
| 同上 + 「UI 按钮」「commit message」「API 文档」 | 采用对应语域与长度 |

**工作区**：项目路径 `D:\work\chinese-english-translation`。若用户 @ 该目录下文件，优先结合文件语境（前后术语一致性）翻译。

## 语种判定（最小输入）

1. 若原文以汉字为主 → **中译英**。
2. 若以拉丁字母英文为主 → **英译中**。
3. 中英混杂：以**用户显性指令**为准；无指令则按句子主表达语种判定。

## 英译「首字母小写」规则（强制）

以下均指**交付的英文译文字符串**的首个**英文字母**小写，除非落入例外。

- **默认**：整段译文作为**词组、标题片段、UI 标签、按钮文案、列表项、技术说明短句**时，**第一个英文字母必须小写**。  
  - 例：中文「保存更改」→ `save changes`（非 `Save changes`）。
- **例外（保持大写）**：
  - **专有名词**：人名、地名、品牌、产品名、RFC 标准名等按英语惯例保留大小写（如 `iOS`、`GitHub`）。
  - **首字母缩略词**：`API`、`URL`、`JSON` 等保持惯例写法。
  - **用户明确要求**句首大写、标题大写（Title Case）或「按英文句子规范」时，从其要求。
- **多句英文**：若用户给出的是连续多句正文且要求出版物/邮件体例，可与用户约定句首大写；**未约定时仍默认每条译文字符串首英文字母小写**（适用于片段式交付）。

若同时给出「标题体」与「默认小写」两版会破坏单一事实来源，**除非用户要两版对比，否则只出一版并采用默认小写规则**。

## 语法与含义说明（强制）

对**英译**或**中译**结果，必须用**简体中文**写清语法层面含义，至少覆盖：

1. **结构**：短语还是完整句；若有从句/非谓语，指出谁修饰谁。
2. **成分**：核心谓语或中心名词、关键介词搭配、宾语与补语关系。
3. **语义**：在本语境下的选定译法理由（一词多义时说明剔除了哪些理解）。
4. **语域**：偏正式/口语/技术文档/UI，以及是否隐含命令、请求或陈述。
5. **可替换性**（如有关）：给出 1 个更正式或更口语的同义替代表达，并注明语域差异。

避免纯词典罗列；说明应让读者**核对「为什么这串英文是这个意思」**。

## 翻译质量清单（自检）

- [ ] 语种方向正确，术语与项目/用户给定上下文一致
- [ ] 英译符合**首字母小写**规则及专有名词例外
- [ ] 无中式英语硬伤；介词、可数名词、时态与语境一致
- [ ] 中译通顺，无过度翻译；数字、单位、标点习惯符合中文排版
- [ ] **语法与含义说明**已写且可核对译义
- [ ] 敏感专名（药名、法规、商标）未臆造；不确定处标明「需业务确认」

## 输出模板（必须遵循）

按顺序输出以下区块（无 emoji；代码与英文例保持字面）：

```markdown
## 方向
中译英 | 英译中

## 原文
[粘贴或引用]

## 译文
[最终采用的一句/一段；英译时首英文字母小写，符合上文例外]

## 语法与含义
[简体中文：结构、成分、语义取舍、语域；必要时分条]

## 备注（可选）
- 术语表建议 / 与相邻文案一致性 / 需用户确认的专名
```

**批量翻译**：每个条目重复「原文 → 译文 → 语法与含义」最小三元组，或用户指定仅输出表格时，在表后附**汇总语法说明**（按条目编号对应）。

## 常见场景补充

- **UI / 按钮**：英译短语优先短小；说明是否为命令式（imperative）及对象省略是否合理。
- **错误提示**：说明语气（用户责任 / 系统故障）是否与中文轻重一致。
- **代码注释**：英译可为片段；说明与代码符号（参数名、类型）的指代关系。
- **英译中**：「首字母小写」规则不适用；重点说明原文难点结构在汉语中的落实方式。

## 边界

- 不捏造不确定的医学、法律、金融结论；不确定时写出**备选译法 + 风险**。
- 不替代人工校对合同或对外法律文书；此类场景在备注中声明。
- 用户仅要「一个字」且不解释时，仍提供**极简语法/语义一句**，以符合本 skill 契约。
