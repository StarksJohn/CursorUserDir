# ask-win11

## 目的

本 skill 是 **Windows 11 侧通用问答与记录入口**（硬件识别、回收与平台操作类问题、与 WIN11 工作区文档同步），用于：

- 首次回应前读取 **全局 ask 模板**（若任务依赖），遵守其中的 **只读约束**与附图/user_rules 约定
- 与 Cursor Command **`ask_WIN11系统问题`**（见下文路径）配合：命令里的 **「当前活跃需求」** 定义本轮具体题目；本 skill 固化 **稳定流程与落盘位置**
- 用 **shell / WMI / 系统工具** 在本机 **实测** 品牌型号与配置，避免仅凭聊天推测
- 将 **对用户持久的结论** 合并进 **`WIN11系统相关问题解决方案.md`**；不把长篇证据只留在对话里（用户未要求新建其它 `.md` 时默认不扩散）

**非目标**：替代 **`ask-BlackScreen`**（黑屏/WHEA/PH18-72 稳定性专项）；替代 **`ask-cursor`**（IDE/MCP/Rules）；替代具体业务仓库的 **`ask-*`**。

## 何时使用

满足以下任一情况时启用本 skill：

- 用户 **`@ask-win11`** 或输入 **`/ask_WIN11系统问题`**、**「WIN11 系统问题」**等与本模块一致的入口
- 工作区或话题锚定在 **`D:\work\WIN11`**，且需要更新 **`WIN11系统相关问题解决方案.md`**
- 问题涉及：**本机硬件盘点**、**二手回收（转转/爱回收等）与型号核对**、Win11 **通用排障线索**（且不落入 BlackScreen 专域）

以下情况 **优先路由到其它 skill**，本 skill 只做简短分流说明：

| 场景 | 优先入口 |
|------|-----------|
| 黑屏/蓝屏/WHEA、MEMORY_MANAGEMENT、负载重启、PH18-72 电源与 BIOS 收敛 | **`ask-BlackScreen`** |
| Cursor 设置、Rules/Skills/MCP、`mcp.json` | **`ask-cursor`** |
| RN/医疗/其它业务仓库 | 对应项目 **`ask-*`** |

## 执行工作流

1. **读模板**：按路径读取 **`ask.md`**，遵守 **禁止修改 ask 系文件**。
2. **读命令（若用户走了 `/ask_WIN11系统问题`）**：读取 **`ask_WIN11系统问题.md`**，解析附图路径并 **先读后推理**。
3. **收敛类型**：硬件盘点 / 回收平台与型号匹配 / 通用 Win11 说明——不在此展开 BlackScreen 深度链。
4. **本机取证**：用 **`wmic`** 或等价方式拉取 `Manufacturer`、`Model`、CPU/GPU/内存/磁盘；PowerShell 长脚本注意 **引用变量与编码**，失败时降级单条命令。
5. **对外部平台**：转转/爱回收等 **给出入口与判别逻辑**（产品线是否一致）；**具体金额以 App/官网实时估价为准**，skill 内区间仅作参考且文档中注明时效。
6. **落盘**：把本轮 **解决方案摘要** 写入 **`WIN11系统相关问题解决方案.md`**（用户要求「总结更新」时必须执行）。

## 输出约定

- 对用户：**简体中文**
- **代码与命令注释**：英文（若附带脚本）
- 引用工作区已有内容时使用规范 **代码引用块**（若在工作区内协作编程）；路径说明写完整路径字符串
- **诚实边界**：无法远程读取转转/爱回收实时报价时明确说明；机型不在列表时建议 **「找不到型号」/ 按配置描述**，禁止让用户选 **明显错误系列**（如 Nitro、擎 Neo 顶替 Helios 18）冒充

## 边界

- **非硬件质检与估价仲裁**：不到手验机、不承诺回收商最终扣款规则。
- **不擅自新建文档**：默认只维护 **`WIN11系统相关问题解决方案.md`**；用户明确要新文件时再建。
- **不合并 unrelated 任务**：稳定性深挖归 **`ask-BlackScreen`**；IDE 归 **`ask-cursor`**。
