### 为何不同手机表现不同？

核心原因：`ref_url` 的更新依赖 WebView 的回调，而这些回调在不同设备、平台上行为不一致。

| 因素 | 说明 |
|------|------|
| **平台差异** | `onShouldStartLoadWithRequest` 在 **Android** 上：首次加载不调用；对 SPA、history 等导航可能不触发 |
| **时序差异** | 支付完成后页面可能从 `completed` 跳转到 `summary` 或 `about:blank`；该跳转何时触发回调、API 何时返回，在不同设备上不同 |
| **单一数据源** | `ref_url` 只在 `onShouldStartLoadWithRequest` 中更新，在 Android 上该回调可能不触发，导致 `ref_url` 与实际 URL 不符 |

因此：

- **能执行到 218 行的手机**：在 API 返回时，`ref_url` 已经是 `about:blank` 或含有 `summary`。
- **执行不到 218 行的手机**：在 API 返回时，`ref_url` 仍是 `completed` 或未更新。
