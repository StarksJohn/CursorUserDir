    fix(global-assistance): stop RN 0.81 crash after long-pressing Home tab
    
    Long-pressing the Home tab opened Global Assistance, then crashed when
    the countdown finished. The device error was TypeError: undefined is
    not a function inside react-native-modal, because RN 0.81 removed
    BackHandler.removeEventListener. ErrorBoundary only showed the generic
    "unknown error, restarting soon" alert.
    
    react-native-modal 13.0.1:
    - Keep the hardwareBackPress subscription from addEventListener.
    - Call subscription.remove() on unmount instead of the deleted API.
    - Persist the change with patch-package so postinstall reapplies it.
    
    Main tab Global Assistance:
    - Keep the react-native-modal mounted and toggle isVisible.
    - After the countdown, close the overlay first and open the contact
      dialog from onModalHide so Android does not unmount one Modal while
      showing another.
    - Cancel/swipe still clears the pending-contact flag.
    
    ErrorBoundary:
    - Log the real error in development so the next crash is not silent.
    
    Co-authored-by: Cursor <cursoragent@cursor.com>
