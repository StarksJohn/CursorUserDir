填表说明

一、本年度报告制表以教育部《依法治教实施纲要（2016-2020年）》《全面推进依法治校实施纲要》等文件为依据，并选取主要内容形成“填写要点”，请根据填写要点逐项进行填写；根据学校实际情况及办学特色，填写内容可以超出“填写要点”的范围。

二、请以简述的形式进行填写，并注意填写内容的量化、要素化，突出重点，避免空洞、宏观的长篇累牍，如报告校内规章制度及相关机制建设，应直接体现文件名称、文号及发文日期，并择要点及特点进行概述。

三、本年度报告制表涉及机制建设等部分内容为常规性填写栏目，学校在首次填写时应当逐项填写，在之后年度中可仅就本年度具体情况予以更新。

四、本表格可附页，对于表格内未尽事宜或需要进一步补充说明的事项，学校可以以附件形式提交。

五、教育行政部门可能根据学校填报情况要求学校提交补充支撑材料。

5.依法保障师生合法权益情况

5.1教师权益维护

l 学校R已建立/□部分建立/□未建立权利义务明确的教师及其他教职员工聘用制度；民办学校□已根据/□未根据工会相关法律法规建立集体劳动合同制度，并请描述涉及教师工资、福利、社会保险等方面的标准及制度。（重点突出学校在2020学年推进相关工作的新举措、新成效）

工资：遵守《义务教育法》依法办学，深刻领会义务教育实施绩效工资改革的意义，认真落实其各项激励性政策，建立与引进科学长效的分配机制，鼓励教师职工爱教爱岗、敬业奉献、精心育人担负民族复兴基业的重任，建设尊重知识、尊重人才与吸引优秀人才从事教育的良好教育环境。要注重绩效工资分配与教师实绩贡献相适应,与学校教育教学特点和规律相适应,与约束和激励相适应，做到薪随事转、多劳多得、优绩优酬，使激励因素贯穿分配的全过程。在鼓励学校全员的“绩效工资”改革政策的基础上，激励政策向一线教师、骨干教师和做出突出贡献的其他岗位工作人员倾斜，加强绩效工资激励导向。聚焦重点教师群体、重点改革攻坚项目，加大考核和激励力度，重点围绕教师承担重大任务、积极参与教育改革、骨干教师发挥示范辐射作用、承担带教培训任务、见习教师指导活动等。鼓励先进奖励优教多劳业绩，调动和保护教师创造性，促进学校素质教育深入发展。在加大激励的同时，要进一步强调惩戒约束，加大对学校和教师办学行为和师德师风、行为规范的考核检查，结果作为绩效工资分配的依据，奖惩分明。

福利：福利费的管理使用遵循厉行节约、反对浪费和量入而出、收支平衡的原则，加强单位的预算管理。福利费的使用应公开透明，重大开支须经“三重一大”审批程序并予以公示。

社会保险：我校从2021年开办至今，参加了《上海市普陀区职工特种重病补充医疗互助保障计划》、《上海市普陀区在职职工住院补充医疗互助保障计划》、《上海市职工保障互助会女职工团体互助医疗特种保障计划》、《上海市职工保障互助会上海市在职职工住院补充医疗互助保障计划》、《上海市职工保障互助会特种重病团体互助医疗保障计划》、《上海市职工保障互助会上海市退休职工住院补充医疗互助保障计划 》六项保障计划，做到全员参保，及时续保、及时理赔，几年以来，效果显著，得到了教职工们的广泛赞扬。

5.3纠纷解决机制

l 请描述校内纠纷解决机制的整体框架，及基层调解组织、教职工（代表）大会、家长委员会、法治工作机构（人员）等在处理纠纷中的作用。（重点突出学校在2020学年推进相关工作的新举措、新成效）

在同级党组织的领导和行政支持下，以工会、人事、家长委员会代表等方面的代表为主要成员，成立教职工（家校）矛盾争议诉求协调工作小组（简称“诉求协调小组”），负责本校的教职工（家校）矛盾争议诉求协调机制的建立、运行和实施。诉求协调小组的工作机构设在工会。诉求协调小组可有3—9人组成，小组成员原则上应为教代会代表。

教职工、学生监护人可通过以下渠道进行诉求：1、口头诉求：教职工、学生监护人可以用电话或直接到诉求协调小组办公室将诉求内容向诉求协调小组反映。2、书面诉求：教职工、学生监护人可以将诉求材料直接递交诉求协调小组。3、网络诉求：教职工、学生监护人将诉求材料通过系统诉求协调小组提供的网络地址直接提交诉求协调小组。一般情况下，当事人应当在争议发生之日起10日内，向诉求协调小组提出诉求。教职工、学生监护人将诉求内容告知诉求协调小组，并提供诉求的具体事项、事实和理由。诉求回应的方法：1、直接给予回复。针对教职工、学生监护人诉求的内容，诉求协调小组在了解相关情况后，需在10个工作日内给予诉求的教职工直接的回复。2、重大而复杂的诉求内容，需通过调解的方法来解决的，可启动协调的工作机制。3、启动协调工作机制来调解矛盾争议的，首先由单位诉求协调小组按有关的程序进行调解协商，合理解决教职工、学生监护人的诉求。4、单位诉求协调小组未能调解成功的，由上报上级诉求协调小组启动协调工作机制来调节矛盾争议。

7.3.学校依法治校本年度特色推进情况、存在问题及下年度工作重点：

2021年9月建校以来，学校通过中心组理论学习、教工大会、党员学习、网络媒体等平台，以法治讲座讲座，专题培训、读书活动、微信推送等形式，定期开展广大教职工的法治教育。面对新冠肺炎疫情，学校针对《突发公共卫生事件应急条例》、《传染病防治法》等内容，响应号召，精准部署，全力以赴做好严防严控工作，研究制定了相关工作预案，全方位、全覆盖地关心、统计师生团队的健康防疫情况，提升师生的自我防护意识和自我防护能力；《上海市生活垃圾管理条例》正式施行以来，结合此项工作，学校通过开展推进垃圾分类工作专项会议、专题学习、讲座、知识问卷等形式，在校园内大力开展垃圾分类环保行动，在全校师生的共同努力下，师生分类意识不断提升，垃圾分类成效显著，师生守法意识不断增强。

利用升旗仪式、大队集会、主题活动周等平台，开展廉洁教育主题活动，并且要求学生在初中阶段重点完成“五个一”活动。即办好一期以廉洁文化内容为主题的黑板报；看一部反腐倡廉内容的影视片，完成感悟；开展一次廉洁教育主题班队会；参加一次廉洁主题征文比赛或演讲比赛；创作一幅廉洁主题书法、电子小报、或漫画作品。

我校的社会实践活动是非常丰富的，军政训练、常规的雏鹰假日小队活动，我们都会有意识地将廉洁文化渗透其中，利用红色资源开展革命传统和爱国主义教育。在军政训练中组织学生学习人民军队的光荣传统，重温三大纪律八项注意，力求在实践活动中潜移默化地提高廉洁教育的有效性。

在今后的工作中，我校将继续扎实推进依法治校工作，加强法治教育力度，进一步完善学校的各项管理制度，做到依法决策、依法管理、依法治教，不断提升办学水平，办人民满意的教育。
