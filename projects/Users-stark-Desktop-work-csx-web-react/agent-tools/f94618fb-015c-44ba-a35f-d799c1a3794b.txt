# 快看：荆江评论：大隐隐于市，小隐隐于mo

2023-05-30 16:13:21 来源：荆州新闻网

【资料图】

荆州新闻网消息（评论员 刘筱奕）近期，一个粉色大脑袋、捏着双肉乎乎小爪子的小恐龙，活跃在各个社交媒体平台上，它有着一个特殊的名字“momo”：TA无处不在，无所不言，却又无迹可寻。

此momo并非某一个特定的人，也并非什么“神秘组织”，最初这个名字和头像只是新用户注册账号后自动生成的默认信息，正如前些年“佚名”一样。随着互联网技术越来越发达，算法推荐越来越智能，“网络考古”越来越频繁，一些习惯“潜水”的网友便索性将头像和昵称换成系统默认，以寻求一份安全感。

许多人对此感到疑惑，网络头像和名称不是用来体现个人特点、展现个人魅力，与其他用户进行区分的吗？为什么要用系统默认的头像和昵称呢？原来，这是互联网用户心理状态正在悄然发生变化。21世纪初期，互联网正处于新兴发展阶段，曾经的用户是多么亢奋地涌向互联网，在网上尽情表达自我。“葬爱家族”“QQ飞车家族”……无一不体现人们希望在互联网展示自己优雅而又特殊的人格。当时的社交平台，人们热衷于分享各类信息，品一杯咖啡、打卡一家冷门餐厅、听一首歌等等，配上冥思苦想的文案，似乎人人都想成为互联网上“特别”的存在。那时候的网民心态是敞开式、分享式的，仿佛所到之处都要大喊一声“xxx来也”。如今，随着网络技术打破时间和空间的距离，现实和虚拟世界边界愈发模糊，虽然个性化网名头像也是一种匿名马甲，但根据智能化算法推荐、过往历史记录，也可能会被熟悉的人推测出真实身份。加之现在社交平台多数要求绑定电话号码，用户的真实身份信息极有可能暴露。此外，各大APP相继推出“可能认识的人”功能，一条吐槽的微博、一个社区的回答、一条玩趣的抖音，都有可能被及时推送给亲友、同事、同学等现实中认识的熟人。

身处信息时代，有人需要在强关系圈中展现社交规范和期待下的“公我”形象，也需要在弱关系圈中释放“私我”的表达欲。披上“马甲”，泯然众“mo”，有了集体掩护的身份，可以极大地减轻社交压力。实现“大隐隐于市，小隐隐于mo”的网络表达欲和分享欲。同质化momo账号在一定程度上也规避了以昵称、头像分类为标签的算法推荐。网友们“改名换头像”，只为网上冲浪时能暂时躲开日常的社交，享受自己的一片天地。

“momo”对于个人来说，或许是一种保护，是和互联网有限度的切割，但是这也让互联网失去了交流的意义，失去了信息分享的乐趣。网民们不再真诚，彼此冷漠，互联网多少失去了它最初实现“地球村”的愿望。与现实身份“断连”的“momo”，有着如同枯叶蝶般的保护色、克隆人般的头像大军、千万条小恐龙的只言片语。正是这层保护套，部分“momo”在一定程度上卸下了现实规范，网络发声变得随心随意。更有甚者，披着可爱的外表，发出恶毒的谩骂。

需要强调的是，网络不是法外之地，“momo”也不是包庇纵容违法言论的保护伞，尽管顶着同样的头像和昵称，通过用户身份证明一样可以锁定到具体的人。“momo”是时代潮流化的产物，在不久的将来，将会涌现出更多类似的“马甲”。根本之策是多一些多元化、包容化、理性化的心态，少一些戾气和过激的情绪，将网络社交规范普遍内化并遵循。一“mo”做事亿“mo”当，“隐身”带来的安全感需要“momo”们共同来守护。
