
--------------- HBuilderX(v5.34.2026102909) cli (v1.0.0.0)--------------
compile app-android	
  通过 CLI 编译 Android 平台 UTS 单文件或单 uni_modules 模块
  用法：./cli compile app-android --help
        ./cli compile app-android --project demo --file src/uni_modules/demo/utssdk/app-android/index.uts
        ./cli compile app-android --project demo --uni_module aa-bb
        说明：--file 与 --uni_module 不能同时指定；--uni_module 可传绝对路径、相对路径，也可只传模块名（如 aa-bb，会自动拼接为项目源码根目录下的 uni_modules/aa-bb）
  参数:
	--help  	查看 UTS 编译 CLI 命令帮助
	--project	HBuilder 中已导入项目的绝对路径
	--file  	要编译的 UTS 文件路径，支持绝对路径或相对项目目录的路径；与 --uni_module 互斥
	--uni_module	要编译的 uni_modules 模块目录，支持绝对路径、相对项目目录路径或模块名简写；与 --file 互斥

decompress wgt	
  通过 CLI 解压 wgt 包，蒸汽模式 wgt 为 zstd 压缩的 zip 归档。
  用法：./cli decompress wgt --help
        ./cli decompress wgt --file /Users/xxx/xxx.wgt [--output /Users/xxx/xxx]
  参数:
	--help  	查看解压 wgt CLI 命令帮助
	--file  	要解压的 .wgt 文件绝对路径 参数 file 为文件路径，请填写一个有效的文件路径
	--output	解压输出目录，不指定时默认解压到 wgt 同名目录

launch app-android	
  通过 CLI 运行到 Android App。文档：https://hx.dcloud.net.cn/cli/launch-app?id=launch-app-android
  用法：./cli launch app-android --help
  参数:
	--help  	查看运行 CLI 命令帮助
	--project	HBuilder 中已导入项目的绝对路径
	--ui    	是否切换为界面运行模式；默认使用纯 CLI 运行，传入 --ui 后通过界面方式启动 取值有[true|false] 默认值为:false
	--deviceId	指定要使用的设备序列号；不指定时默认使用第一个设备，可通过 devices list 获取设备列表
	--playground	基座类型；custom 时可通过 customType 选择本地基座或已安装基座 取值有[standard|custom] 默认值为:standard
	--customType	自定义基座类型；local 为本地基座，device 为设备上已安装的基座（需 playground=custom） 取值有[local|device] 默认值为:local
	--packageName	设备上已安装基座的 Android 包名（customType=device 时必填）
	--localRepoPath	已安装基座关联的 Android 原生工程路径（customType=device 时可选）
	--native-log	是否显示原生日志 取值有[true|false] 默认值为:false
	--cleanCache	是否清理构建缓存（仅 uni-app x 项目生效） 取值有[true|false] 默认值为:false
	--vaporRenderTarget	视图层编译目标，可选 bytecode 或 nativecode（仅 uni-app x 蒸汽模式生效） 取值有[bytecode|nativecode] 默认值为:bytecode
	--compile	是否以编译模式运行，仅编译代码 取值有[true|false] 默认值为:false
	--continue-on-error	编译出错后是否继续运行 取值有[true|false] 默认值为:false
	--runtime-log-format	运行时日志输出格式；formatted 为现有格式化日志，raw 为设备原始结构化日志 取值有[formatted|raw] 默认值为:formatted
	--pagePath	启动页面路径
	--pageQuery	启动页面查询参数，多个参数使用 & 连接
