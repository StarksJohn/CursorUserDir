## 📊 零成本部署方案调研 (2026年2月)

### 问题1: 是否只有 Vercel + Supabase 能实现0成本免费部署?

**结论: 不是唯一方案,但仍是 Next.js 全栈项目的最佳选择之一。**

#### 其他0成本部署方案对比

| 方案 | 前端/托管 | 数据库 | 适用场景 | Next.js 支持 | 持续免费 |
|------|-----------|--------|----------|--------------|----------|
| **Vercel + Supabase** | Vercel Hobby | Supabase Free | Next.js 全栈 | 原生最佳 | 是 |
| **Cloudflare Pages + Workers + Supabase** | Cloudflare | Supabase Free | 全栈应用 | 需 @cloudflare/next-on-pages | 是 |
| **Netlify + Supabase** | Netlify Free | Supabase Free | Next.js/静态 | 良好 | 是 |
| **Render + Supabase** | Render Free | Supabase Free | 全栈 | 支持 | 服务15分钟无活跃后休眠 |
| **Fly.io + Supabase** | Fly.io | Supabase Free | 全栈 | 支持 | 有限免费额度 |

#### 为什么 Vercel + Supabase 仍是 LeaseGuard 首选?

1. **Next.js 原生支持**: Vercel 是 Next.js 官方推荐平台,零配置部署
2. **全栈能力**: Server Actions、API Routes、中间件开箱即用
3. **无休眠限制**: 与 Render 不同,Vercel 免费版不因无活跃而休眠
4. **数据库稳定**: Supabase Free 提供 500MB 数据库 + 1GB 存储,无过期限制
5. **生态成熟**: 文档完善,社区活跃,问题易排查

#### 可选替代方案: Cloudflare 全栈免费

若因网络原因无法使用 Vercel,可考虑:

```
前端: Cloudflare Pages (Next.js 需 @cloudflare/next-on-pages 适配器)
API: Cloudflare Workers
数据库: Supabase (保持不变)
```

**注意**: Next.js 部署到 Cloudflare 需额外配置,不如 Vercel 便捷。

---

### 问题2: 中国大陆境内云平台是不是都要收费?

**结论: 国内云平台有免费试用额度,但长期运营需付费。真正的长期0成本部署需用海外平台。**

#### 国内云平台免费额度现状 (2025-2026)

| 平台 | 免费产品 | 免费额度 | 有效期 | 限制说明 |
|------|----------|----------|--------|----------|
| **腾讯云** | COS 对象存储 | 50GB + 10GB/月流量 | 6个月 | 需实名认证 |
| **腾讯云** | 云服务器 CVM | 1-2核试用 | 1-2个月 | 新用户专属 |
| **阿里云** | OSS 对象存储 | 40GB | 6个月 | **无免费流量**,需另购 |
| **阿里云** | ECS 云服务器 | 2核2G | 750小时/月 | 新用户,约等于1台常开 |
| **华为云** | OBS 对象存储 | 10GB | 永久 | 仅1GB流量,不适合生产 |

#### 为什么国内云「免费」不等于0成本?

1. **时效限制**: 免费额度多为 6 个月或 1-2 个月,到期后必须付费
2. **实名与备案**: 需完成实名认证,网站需 ICP 备案 (15-30 天)
3. **组件需组合**: 全栈应用需 ECS + RDS + OSS 组合,免费额度难以覆盖全部
4. **流量成本**: 阿里云 OSS 无免费流量,公网流量按量计费
5. **运维成本**: 需自建 Nginx、SSL、防火墙、监控等

#### 国内云长期运营成本估算

全栈应用 (Next.js + PostgreSQL + 文件存储) 正式运行:

| 服务 | 配置 | 月成本 |
|------|------|--------|
| 应用托管 | 2核4G ECS/轻量 | ¥120-200 |
| 数据库 | RDS PostgreSQL 基础版 | ¥80-150 |
| 对象存储 | OSS/COS 50GB | ¥10-20 |
| CDN (可选) | 国内流量包 | ¥50 |
| **合计** | - | **¥260-420/月** |

**结论**: 国内云适合 V2 正式运营阶段,不适合 V1 MVP 0 成本验证。真正的长期 0 成本部署应使用 Vercel + Supabase 等海外免费平台。

## 调研结论总结

### 1. 是否只有 Vercel + Supabase 才能实现 0 成本免费部署？

**不是唯一方案，但仍是 Next.js 全栈项目的首选之一。**

其他可实现 0 成本的方案包括：

- **Cloudflare Pages + Workers + Supabase**：完全免费，但需要适配 `@cloudflare/next-on-pages`
- **Netlify + Supabase**：对 Next.js 支持较好
- **Render + Supabase**：免费版在 15 分钟无活跃后会自动休眠，不适合需要持续在线的应用

Vercel + Supabase 仍然是 LeaseGuard 的推荐组合，主要因为：

- Next.js 原生支持好，几乎零配置
- 无休眠限制，免费版可长期运行
- Supabase 免费额度稳定（500MB 数据库、1GB 存储，无固定过期限制）

---

### 2. 中国大陆云平台是否都要收费？

**有免费试用额度，但长期运营一般需要付费。**

| 平台     | 免费额度               | 限制说明                         |
|----------|------------------------|----------------------------------|
| 腾讯云   | COS 50GB + 10GB/月流量 | 有效期 6 个月，需实名认证        |
| 阿里云   | OSS 40GB              | 有效期 6 个月，**无免费流量**    |
| 华为云   | OBS 10GB 永久         | 仅 1GB 流量，不适合正式生产环境 |

国内云的局限：

1. 免费多为 6 个月或短期试用，到期后需转为付费
2. 全栈应用需 ECS + RDS + 存储 组合，整体难以做到长期 0 成本
3. 正式上线需要 ICP 备案（约 15–30 天）
4. 长期稳定运行月成本大致在 ¥260–420
